# Project 3: Computational Physics

This repository contains the code and documentation for Project 3 in the FYS3150 - Computational Physics course at the University of Oslo.

## Folders 
- code/
  
  Contains all code used to generate results for this project. See specifically [code/readme.md](https://github.uio.no/icrukan/FYS4150/blob/master/Project3/code/readme.md) for a detailed presentation of how to run the code.
  
- figs/
  
  Contains all figures used in main.tex, see specifically Figs/results/

- docs/
  Contains documentation of the code struture generated using doxygen [doxygen](https://www.doxygen.nl/)
